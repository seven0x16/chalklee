# External app logos

These local assets identify the external apps in connection settings.
Brand artwork and trademarks belong to their respective owners.

- `doubao-work.png`: rounded application icon from Doubao Work 2.35.19,
  `DoubaoWork.app/Contents/Resources/app.icns`. The 1024×1024 representation
  is cropped to its 824×824 tile (offset 100, 100), then reduced to 256×256.
  Product website: <https://www.doubao.com/work>.
- `qwen-work.png`: rounded application icon from QwenWork CN 1.5.0,
  `QwenWorkCN.app/Contents/Resources/icon.icns`. The 256×256 representation
  is cropped to a 208×208 tile (offset 24, 24), retaining its edge highlight.
  Product website: <https://qwenwork.cn/>.

The crops remove the outer macOS icon padding. The original rounded backgrounds,
brand colors, and artwork are retained; neither icon is redrawn.

WorkBuddy and Codex reuse assets in `../ai-providers/`; see that directory's
source attribution and MIT license.
